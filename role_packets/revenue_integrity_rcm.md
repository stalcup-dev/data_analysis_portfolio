## Evidence Chain I Build Around

| Step | What I analyze |
|---|---|
| Performed activity | Visit, procedure, lab, service, or encounter that should create downstream work or revenue |
| Expected state | What should have been billed, routed, documented, corrected, or reconciled |
| Actual state | Missing, held, denied, delayed, underdocumented, aged, or already lost |
| Failed control | Which process checkpoint failed to catch the issue earlier |
| Current blocker | Documentation, coding, billing hold, payer issue, eligibility issue, or operational ownership gap |
| Owner | The queue, role, or function responsible for the next action |
| Recoverability | Whether the issue is still financially recoverable or operationally actionable |
| Next move | The specific follow-up action, not just a dashboard observation |
